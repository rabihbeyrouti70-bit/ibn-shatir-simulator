# محاكي ابن الشاطر وبطلميوس الفلكي المقارن (نسخة React.js المعيارية)

نسخة حديثة ومعيارية بالكامل من المحاكي الفلكي التراثي والمقارن، مبنية باستخدام **React 19 + TypeScript + Vite**، ومصممة بأعلى معايير جودة الكود وتجربة المستخدم (UI/UX).

---

## 🚀 التشغيل السريع:

### تشغيل خادم التطوير المحلي:
```bash
npm run dev
```
أو انقر نقراً مزدوجاً على الملف: `run_react_dev.bat`.

### بناء النسخة الإنتاجية (Production Build):
```bash
npm run build
```

## ✨ المميزات المعيارية للنسخة الجديدة:
1. **فصل كامل للمسؤوليات (Clean Architecture):** لا توجد أي حسابات فلكية مدمجة داخل الكانفاس؛ فمحرك الحسابات نقي تماماً في `astroMath.ts`.
2. **عرض جنباً إلى جنب دائم (Strict Side-by-Side):** نماذج الشمس والقمر والكواكب معروضة في شبكة ثنائية الأعمدة دائمة تمنع الالتفاف.
3. **أداء فائق واستقرار في الذاكرة:** التخلص من المتغيرات العامة وتوظيف `useRef` و `useCallback` و `useMemo` لضمان 60 إطاراً في الثانية دون أي تسريب للذاكرة.
4. **دعم شاشات العرض العالية الدقة (Retina & High-DPI):** رسومات الكانفاس تتجاوب بسلاسة دون فقدان الدقة.
