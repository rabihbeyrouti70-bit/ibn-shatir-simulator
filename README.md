# 🌌 منظومة محاكيات ابن الشاطر الفلكية ونهاية السول في تصحيح الأصول
### Ibn al-Shatir Historical Astronomy Simulator & Computational Manuscript Suite

منظومة تفاعلية شاملة لإحياء وتجسيد النماذج الفلكية الرياضية للعالم الفلكي الدمشقي **علاء الدين علي بن إبراهيم بن الشاطر الأنصاري (704 - 777 هـ / 1304 - 1375 م)**، مؤقت الجامع الأموي الكبير بدمشق ومؤسس الهندسة الفلكية الحديثة القائمة على انتظام الحركة الدائرية وإلغاء فلك التدوير البطلمي ونقطة معدل المسير (Equant).

كما تتضمن المنظومة **المحاكي المقارن للثورة الفلكية** (ابن الشاطر vs نيكولاس كوبرنيكوس vs يوهانس كيبلر) لإظهار أثر نماذج ابن الشاطر على كوبرنيكوس بعد مئتي سنة، وتبيان كيف كان ابن الشاطر سيرى مدارات كيبلر الإهليلجية البيضاوية إخلالاً بالمبادئ الهندسية للأجرام السماوية.

## 🌟 المحتويات والتطبيقات التفاعلية

### 1. 🪐 المحاكي المقارن الموحد (`index.html` / `محاكي_ابن_الشاطر_المقارن.html`)
المحاكي الرئيسي الشامل الذي يعمل مباشرة في أي متصفح ويب بدون أي تثبيت، ويحتوي على 6 بوابات علمية:
* **بوابة الشمس (Solar Model):** نموذج التدوير الثنائي (فلك تدوير أول وثانٍ متزامنان)، مع إلغاء الفلك الخارج المركز لبطلميوس وضبط الأوج والشمس وتعديل المركز الأعظم ($2^\circ 2' 6''$).
* **بوابة القمر (Lunar Model):** حل المعضلة الكبرى لبطلميوس؛ حيث صحح ابن الشاطر بُعد القمر في التربيعين وحافظ على القطر الظاهري الصحيح للقمر بدلاً من تضاعفه الخاطئ عند بطلميوس.
* **بوابة الكواكب (Planetary Models):** نماذج الكواكب العلوية والسفلية (زحل، المشتري، المريخ، الزهرة، عطارد ومزدوجة الطوسي).
* **بوابة فلك الأطلس والكون الكامل (Cosmos Atlas Sphere):** تمثيل الأفلاك التسعة متحدة المركز والحركة اليومية العظمى من الشرق إلى الغرب.
* **بوابة التقويم ومنازل القمر والبروج (Zodiac & Mansions):** حساب الطول البروجي للشمس والقمر، المنازل الـ 28، والبروج الإثني عشر آنياً مع محرك الزمن الفلكي.
* **بوابة مقارنة الثورة الفلكية (ابن الشاطر vs كوبرنيكوس vs كيبلر):**
  * مقارنة متزامنة لمركزية الأرض (ابن الشاطر - دوائر نظامية متداخلة).
  * مركزية الشمس الدائرية (كوبرنيكوس - استخدم نفس تدويرات ابن الشاطر الرياضية).
  * مركزية الشمس البيضاوية (كيبلر - المدارات الإهليلجية وقانون المساحات).
  * ديناميكا مدار القمر في النماذج الثلاثة.
  * لوحة النقد الهندسي لابن الشاطر لتبيان المفارقات الفلسفية والرياضية.

### 2. 🚀 تطبيق React ثلاثي الأبعاد (`ibn-shatir-react`)
تطبيق ويب متقدم مبني بـ **React 18 + Vite + Three.js + Tailwind CSS**، يوفر كاميرا مدارية 3D ورندرة سينمائية للأفلاك السماوية وحسابات دقيقة للمتجهات الفلكية.

### 3. 📐 الأطلس الهندسي والمخططات المتجهية (`مخططات_ابن_الشاطر_الهندسية/`)
مجموعة كاملة من المخططات الفلكية بصيغتي **SVG المتجهية** و **PNG فائقة الدقة**، معاد رسمها هندسياً بدقة متناهية وفقاً للنصوص والأبعاد المذكورة في مخطوطة *نهاية السول في تصحيح الأصول*.

### 4. 📜 تحقيق المخطوطات والتحليل المعجمي
* النص الكامل المحقق لمخطوطة **«نهاية السول في تصحيح الأصول»**.
* شروح الرسالة الجيبية ورسائل الفجر والأسباب والعلامات.
* أدوات استخراج وتدقيق معجمي بالحاسوب.

## 💻 التشغيل المحلي (Local Setup)

### تشغيل المحاكي الموحد فوراً:
فقط افتح الملف `index.html` أو `محاكي_ابن_الشاطر_المقارن.html` في أي متصفح حديث (Chrome, Edge, Firefox, Safari).

### تشغيل تطبيق React 3D:
```bash
cd ibn-shatir-react
npm install
npm run dev
```
